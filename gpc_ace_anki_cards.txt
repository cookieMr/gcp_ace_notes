Does Transfer Appliance support continuous, real-time data synchronization?	<b>No</b>. It is designed for <b>one-time</b>, large-scale migrations. Use Storage Transfer Service (STS) for recurring sync.

What is <b>Cloud Router</b>?	A fully managed BGP routing service that dynamically exchanges routes between your Google Cloud VPC and on-premises networks, eliminating the need for static routes.
What is <b>BGP (Border Gateway Protocol)</b>?	The core routing protocol of the internet that allows different networks to exchange reachability information. It uses TCP port 179 and maintains connections between autonomous systems to share routing tables.
What is an <b>ASN (Autonomous System Number)</b>?	A unique identifier assigned to an autonomous system (AS) for BGP routing. Private ASNs range from 64512-65534. Each network on both sides of a BGP peering must have an ASN to establish the session.
When is <b>Cloud Router required</b>?	<ul><li><b>HA VPN</b> - Both classic and HA VPN implementations</li><li><b>Dedicated Interconnect</b> - For dynamic routing to on-premises</li><li><b>Partner Interconnect</b> - When using a service provider for hybrid connectivity</li></ul>
What are the <b>key features</b> of Cloud Router?	<ul><li><b>BGP Protocol</b> - MD5-authenticated sessions for secure route exchange</li><li><b>Dynamic Updates</b> - Automatically learns new VPC subnets</li><li><b>High Availability</b> - Managed redundancy across zones</li><li><b>Custom Advertisements</b> - Control which routes are advertised</li><li><b>Route Priority</b> - Configurable for traffic engineering</li></ul>
What is the difference between <b>DEFAULT</b> and <b>CUSTOM</b> route advertisement modes?	<ul><li><b>DEFAULT</b>: Advertises all VPC subnets with RFC 1918 ranges</li><li><b>CUSTOM</b>: Only advertises prefixes you explicitly configure</li></ul>
What does <b>DEFAULT</b> mode automatically advertise in Cloud Router?	<ul><li>All connected subnets in the VPC</li><li>Static routes you've configured</li><li>Routes from Cloud NAT</li></ul>
What are the <b>BGP session details</b> for Cloud Router?	<ul><li><b>BGP Port</b>: TCP 179</li><li><b>Keepalive Interval</b>: 20 seconds (default)</li><li><b>Hold Timer</b>: 60 seconds (default)</li><li><b>MD5 Authentication</b>: Supported and recommended</li><li><b>Peer IP Addresses</b>: Use <code>169.254.0.0/30</code> link-local range</li></ul>
What Cloud Router <b>doesn't</b> do?	<ul><li>It does <b>not</b> route traffic itself - it only manages route exchange</li><li>It is <b>not</b> used for VPC-to-VPC routing (use VPC Peering or TGW)</li></ul>
What are common <b>troubleshooting steps</b> for Cloud Router?	<ul><li><b>Routes not exchanged</b>: Check BGP session state; verify firewall allows port 179</li><li><b>One direction only</b>: Check route advertisements match expected prefixes</li><li><b>Flapping connection</b>: Verify BGP timers (hold-time should be &gt;= 3x keepalive)</li></ul>
How does Cloud Router compare to <b>Static Routes</b>, <b>VPC Peering</b>, and <b>Cloud NAT</b>?	<ul><li><b>Cloud Router</b>: Hybrid cloud connectivity, Dynamic (BGP)</li><li><b>Static Routes</b>: Simple single-hops, Manual</li><li><b>VPC Peering</b>: VPC-to-VPC, no BGP needed</li><li><b>Cloud NAT</b>: Outbound internet for private VMs, no BGP</li></ul>
What is the <code>hold-time</code> vs <code>keepalive</code> relationship in Cloud Router?	The <b>hold-time</b> should be at least <b>3x the keepalive interval</b>.<br>Defaults:<br><ul><br><li><code>keepalive=20s,</code></li><br><li><code>hold-time=60s.</code></li><br></ul>
Can Cloud Router be used for <b>VPC-to-VPC routing</b>?	<b>No.</b> Use VPC Peering or Cloud VPN for VPC-to-VPC connectivity. Cloud Router is for hybrid (on-premises to GCP) connectivity.
What happens if BGP hold-timer expires in Cloud Router?	The BGP session is considered <b>down</b> and routes learned via that session are <b>withdrawn</b>, triggering failover to alternate paths.
What happens when a <b>VPN tunnel fails</b> in an HA VPN setup with Cloud Router?	Cloud Router automatically detects the failure via BGP and <b>failover</b> to the remaining tunnel occurs without manual intervention.
True or False: Cloud Router requires a <b>static external IP address</b> on the Cloud Router itself.	<b>False.</b> Cloud Router uses <b>link-local addresses</b> (<code>169.254.0.0/30</code>) for BGP peering, not static external IPs.
What is the range of <b>private ASNs</b> that can be used with Cloud Router?	<b>64512 to 65534</b>.
Can Cloud Router advertise <b>custom IP ranges</b> that are not in your VPC?	<b>Yes.</b> In <code>CUSTOM</code> advertisement mode, you can advertise any prefix, including ranges not in your VPC (e.g., 172.16.0.0/12).
Is Cloud Router a <b>global</b> or <b>regional</b> resource?	Cloud Router is a <b>regional</b> resource. You must create separate Cloud Routers in each region where you need dynamic routing.
What is the relationship between <b>Cloud Router</b> and <b>Cloud NAT</b>?	Cloud Router is <b>required</b> to create a Cloud NAT gateway. Cloud Router manages the routes while Cloud NAT provides outbound internet for private VMs.
